# 萬軍破陣

直向的人海對衝遊戲，做成可安裝的網頁 App（PWA）。不需要帳號，手機點開就能玩。

傳給 LINE 上的朋友時，網址後面加 `?openExternalBrowser=1`，連結會用手機的瀏覽器開啟（LINE 內建瀏覽器不能安裝到主畫面）。遊戲裡的「分享給朋友」按鈕會自動加上。

## 玩法

- 左右拖曳畫面移動兵砲，士兵會自動連發。讓他們穿過藍色的倍增門（×2、×3…），人數當場翻倍。
- 紅色的折兵門（÷2）會讓隊伍減半，要避開。金色的黃金門倍數很高，但只能用幾十次、過一陣子就消失。
- 我軍和赤潮一碰就同歸於盡。兵比對面多，戰線就往前推；推到敵城門口，每個衝進去的兵扣敵城一點兵力，扣到 0 就攻破。
- 敵城上的數字是「兵力」：敵城每出一個兵也會少一點，但最後一成一定要我軍殺進去。
- 赤潮碰到我方城牆會扣城牆。城牆剩一半時會自動「烽火反擊」一次，把前庭的敵人燒退；城牆歸零就輸了。
- 「大將」每隔一陣子自動從兵砲射出去，落地炸開一圈，再往前衝殺幾秒。
- 右下角的「箭雨」靠殺敵集氣，集滿後按下去，戰線前方一大片敵人直接倒下。
- 第三關起有石座，把兵送進去蓋砲塔（連弩車、轟天砲）；第四關起有火藥桶，撞開就炸。
- 五關：青草關、黃沙谷、霜雪嶺、熔岩道、魔王城。最後一關攻破城門後要再打倒赤潮魔王。
- 過關拿戰利品，在「強化」換砲速、精兵、大將、箭雨、城牆。「設定」可以調難度（輕鬆／標準／硬仗）。
- 電腦：滑鼠移動或方向鍵／A、D 移動兵砲，空白鍵放箭雨，P 或 Esc 暫停。

## 檔案

| 路徑 | 內容 |
| --- | --- |
| `index.html` `sw.js` `manifest.webmanifest` | 上線的網頁 App，由建置腳本產生，不要直接改 |
| `icon-*.png` `apple-touch-icon.png` `og.png` | App 圖示與連結預覽圖 |
| `src/parts/` | 遊戲原始碼，依檔名順序串接 |
| `src/webparts/` | 網頁 App 專用：分享與安裝按鈕、離線快取、manifest |
| `src/build.py` | 建置腳本 |
| `src/gen_icons.py` | 重新產生圖示與預覽圖（需要 playwright、pillow） |
| `test/` | 自動玩家與測試：`sim.js`／`sweep1.js` 在 Node 裡跑戰局估難度，`scene.py`／`e2e.py` 用無頭瀏覽器截圖與走流程 |

## 修改與上線

```
python3 src/build.py https://<帳號>.github.io/<repo>/    # 重新產生 index.html、sw.js、manifest
git add -A && git commit -m "..." && git push
```

GitHub Pages 從 `main` 分支根目錄發布，推上去約一分鐘後生效。每次建置會換一個離線快取名稱，玩家下次連線開啟就會拿到新版。

不帶網址執行 `python3 src/build.py` 只會產生 `src/dist/`：`wanjun.html` 是 Claude Artifact 用的頁面片段，`index.html` 是本機測試用的完整頁面。

## 調整難度

- 關卡資料在 `src/parts/60-levels.js`：`flow`（敵城每秒出兵數）、`fort`（敵城兵力）、`vC`／`vP`（赤潮在隘道／高台的行軍速度，越快越難守）、`gates`（各道門的位置、寬度、倍數、移動幅度）、`script`（依時間出現的黃金門、狼騎、蠻兵、巨魔）。
- 難度三檔的倍率在 `src/parts/50-sim.js` 的 `DIFFS`。
- 改完用自動玩家估一下：`node test/sweep1.js <關卡> <強化等級>` 會印出很會玩／普通／新手三種自動玩家的勝率、用時與剩餘城牆。
