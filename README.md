# 萬軍破陣

直向的人海對衝遊戲，做成可安裝的網頁 App（PWA）。不需要帳號，手機點開就能玩。

**線上遊玩：<https://wayuanzi-web.github.io/legion/>**

傳給 LINE 上的朋友時，網址後面加 `?openExternalBrowser=1`（<https://wayuanzi-web.github.io/legion/?openExternalBrowser=1>），連結會用手機的瀏覽器開啟（LINE 內建瀏覽器不能安裝到主畫面）。主畫面左上角的「分享」按鈕會自動加上。

## 破陣玩法（第 1–5、7、9 關）

- 左右拖曳畫面移動兵砲，士兵會自動連發。讓他們穿過藍色的倍增門（×2、×3…），人數當場翻倍。
- 紅色的折兵門（÷2）會讓隊伍減半，要避開。金色的黃金門倍數很高，但只能用幾十次、過一陣子就消失。
- 我軍和赤潮一碰就同歸於盡。兵比對面多，戰線就往前推；推到敵城門口，每個衝進去的兵扣敵城一點兵力，扣到 0 就攻破。
- 敵城上的數字是「兵力」：敵城每出一個兵也會少一點，但最後一成一定要我軍殺進去。
- 赤潮碰到我方城牆會扣城牆。城牆剩一半時會自動「烽火反擊」一次，把前庭的敵人燒退；城牆歸零就輸了。
- 「大將」每隔一陣子自動出陣，落地炸開一圈，再往前衝殺幾秒。右下角的「箭雨」靠殺敵集氣，集滿後按下去，戰線前方一大片敵人直接倒下。
- 第三關起有石座，把兵送進去蓋砲塔（連弩車、轟天砲）；第四關起有火藥桶，撞開就炸。
- 第七關的**赤門**是敵軍的倍增門：赤潮穿過去會變兩倍，要把兵送上去撞垮（門上的數字是還要撞幾下）。**陰陽門**會在藍色的倍數和紅色的 ÷2 之間輪替，看準顏色再送兵。
- 第九關左邊的**水閘**：送進足夠的兵就開閘，大水把隘道裡的敵軍整片沖走。之後每次要的兵會變多。

## 行軍玩法（第 6、8、10 關）

- 部隊留在畫面下方自己往前走，左右拖曳帶隊。部隊會自動放箭，人越多箭越密。
- **加號門**（+N）整道門只算一次，但會被箭射大，對準它多射一會兒再穿過去。紅色的負數門會扣兵，可以繞開，也可以用箭把它射成正的。乘法門（×N）每個穿過去的兵都算。同一排的門只能選一道。
- **木桶**上的數字是要射幾箭：射破可以救出援兵（藍色小兵）、拿到更強的弓（藍色弓）、放出跟著隊伍走的機關車（木籠）。來不及射破就別硬撞，撞一下賠一個兵。火藥桶射爆會炸飛旁邊的敵人。
- 把隊伍往欄杆靠，整團人會擠成一條長龍，鑽得過半邊的**缺口**、躲得開**滾刀**和**火線**。士兵不會自己走進缺口或火裡，只有站在裡面來不及離開的會陣亡。
- 第六、八關終點是**橋頭堡**，到了就全軍衝鋒，規則跟攻城一樣，所以帶到的兵要比堡上的數字多。
- 第十關途中赤龍會俯衝噴火（橋面先亮紅色火線預告），終點是**赤龍**本尊：對準牠放箭，兵越多牠掉血越快；血剩一半會暴怒，一次燒掉隊伍所在的那半邊橋面。
- 全軍覆沒時「後軍」會趕到救一次，再倒就輸了。星等看過關時剩多少兵。

過關拿戰利品，在「強化」換砲速、精兵、大將、箭雨、城牆（行軍關對應成箭速和開局兵力）。「設定」可以調難度（輕鬆／標準／硬仗）。電腦上用滑鼠或方向鍵／A、D 移動，空白鍵放箭雨，P 或 Esc 暫停。

## 檔案

| 路徑 | 內容 |
| --- | --- |
| `index.html` `sw.js` `manifest.webmanifest` | 上線的網頁 App，由建置腳本產生，不要直接改 |
| `icon-*.png` `apple-touch-icon.png` `og.png` | App 圖示與連結預覽圖 |
| `src/parts/` | 遊戲原始碼，依檔名順序串接。`50-sim` 破陣規則、`52-march` 行軍規則、`53-mech` 赤門／陰陽門／水閘、`60-levels` 關卡資料、`65-bot` 自動玩家 |
| `src/webparts/` | 網頁 App 專用：分享與安裝按鈕、離線快取、manifest |
| `src/build.py` | 建置腳本 |
| `src/gen_icons.py` | 重新產生圖示與預覽圖（需要 playwright、pillow） |
| `test/` | 自動玩家與測試，見下 |

## 修改與上線

```
python3 src/build.py https://wayuanzi-web.github.io/legion/    # 重新產生 index.html、sw.js、manifest
git add -A && git commit -m "..." && git push
```

GitHub Pages 從 `main` 分支根目錄發布，推上去約一分鐘後生效。每次建置會換一個離線快取名稱，玩家下次連線開啟就會拿到新版。

不帶網址執行 `python3 src/build.py` 只會產生 `src/dist/`：`wanjun.html` 是 Claude Artifact 用的頁面片段，`index.html` 是本機測試用的完整頁面。

## 調整難度與測試

- 關卡資料在 `src/parts/60-levels.js`，欄位說明寫在檔案裡的註解。破陣關主要調 `flow`（敵城每秒出兵數）、`fort`（敵城兵力）、`vC`／`vP`（赤潮行軍速度）、`gates`、`script`；行軍關是一條 `track`（每個項目的 `d` 是離起點多遠），另外有 `fortN`（橋頭堡兵力）、`dragonHp`、`s3`／`s2`（三星、兩星要剩多少兵）。
- 難度三檔的倍率在 `src/parts/50-sim.js` 的 `DIFFS`。
- 改完用自動玩家估一下（很會玩／普通／新手三種）：
  - 破陣關：`node test/sweep1.js <關卡> <強化等級>`，印出勝率、用時、剩餘城牆。
  - 行軍關：`node test/march.js <關卡> <強化等級>`，印出勝率、用時、過關兵力；`WHY=1` 會列出輸掉的場次是怎麼死的，`BOTS=fix:3.5` 可以測「站著不動」。
  - 環境變數 `DIFF=0|1|2` 換難度、`N=` 每種跑幾場。
- `node test/regress.js | md5sum`：前五關的戰局摘要。改行軍關或新機關時用它確認前五關沒被動到（目前是 `99b388f42f2b81e664a2b2f49e710d82`）。
- `node test/term.js`：十關 × 四種自動玩家 × 三種難度 × 兩種強化，確認每一場都分得出勝負、座標沒有壞掉。
- 瀏覽器測試（需要 playwright）：`test/e2e.py`、`e2e2.py`、`e2e3.py` 走完整流程，`test/scene.py <情境>` 推到指定時間截圖，`test/home.py <寬> <高>` 看主畫面，`test/save.py` 測舊存檔相容。截圖很慢的機器加 `WJ_GPU=0`。
